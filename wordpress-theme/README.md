# CompanyFlow WordPress package

This folder is the WordPress wrapper for the **original CompanyFlow React/Vite site** in this repository. It does not recreate the site with simplified PHP mockups: the GitHub Actions workflow builds the existing React app, including its routes, project content, service content, resources, team/company sections, original visual styling, animations, images, and WhatsApp widget, then bundles the built site inside a WordPress-installable theme.

## Build the ZIP

1. Open the repository's **Actions** tab.
2. Select **Build CompanyFlow WordPress theme**.
3. Choose **Run workflow** on the `wordpress-ready-package` branch, or let the branch-push build finish.
4. Open the successful run and download the `companyflow-wordpress-theme` artifact.
5. Extract the artifact ZIP. Inside is `companyflow-wordpress-theme.zip`, the theme to upload to WordPress.

## Install

1. Back up your WordPress/LocalWP site.
2. In WordPress Admin, open **Appearance → Themes → Add New Theme → Upload Theme**.
3. Upload `companyflow-wordpress-theme.zip`, install it, then activate **CompanyFlow Original**.
4. Visit **Settings → Permalinks** and click **Save Changes** once to refresh the static-asset routing rules.

## What this package preserves

- Original React website layout and styling, not the previous simplified migration theme
- Existing case studies, services, blog/resource pages, careers and company content from the repository
- Original images and built front-end assets
- Existing WhatsApp widget, which opens WhatsApp at the phone number already configured in `src/components/WhatsAppWidget.tsx`
- Clean routes and route-specific HTML shells generated by the repository build

## Important WordPress/backend note

This package runs the original front end inside WordPress. It does not automatically convert the content into editable WordPress posts, and Netlify Functions are not hosted by WordPress. Any form submission, AI chat, or calendar feature that depends on `/.netlify/functions/*` still needs a WordPress-compatible backend or external service configuration before production launch. The WhatsApp link itself is a direct `wa.me` link. Test all routes and interactive features on a staging/local site before replacing a live site.

## Source safety

Do not copy private API keys into the theme. Configure secrets in the appropriate hosting environment and rotate any credentials that have previously been exposed.
